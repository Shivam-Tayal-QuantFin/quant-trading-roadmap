### 💰 Finance — Stock Returns and Risk

Applied financial concepts while developing the Stock Market Data Analyzer.

Topics explored:

* Daily stock returns
* Total percentage returns
* Average stock prices
* Price variation and standard deviation
* Comparing and ranking stocks based on returns

**Quantitative connection:**

Daily Return:

`Daily Return = ((P_t - P_(t-1)) / P_(t-1)) × 100`

Total Return:

`Total Return = ((P_final - P_initial) / P_initial) × 100`

Standard deviation helps measure the dispersion of stock prices around their mean. However, standard deviation of prices is not the same as return volatility, which is generally measured using the standard deviation of returns.
